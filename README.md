# CUMCM Team AI

面向全国大学生数学建模竞赛的三人 AI 辅助协作 skill。

它提供：

- 2026 国赛规则核查与 AI 使用披露流程
- 三人模型、数据求解、论文交付分工
- 带输入版本、验收条件和复核人的 AI 任务卡
- 代码、结果、公式和论文的一致性检查
- 72 小时内部计划、提交缓冲和睡眠安排

## 安装到 Codex 项目

将本目录放到项目的 `.agents/skills/cumcm-team-ai/`，然后在项目中使用：

```text
使用 $cumcm-team-ai 开始规划国赛协作
```

正式比赛前和提交前都应重新核对官方规则及学校、赛区的补充要求。本 skill 的规则文件提供官方链接，但不替代当届公告。

## 目录

- `SKILL.md`：入口工作流与使用边界
- `references/`：规则、分工、排期、学习资料和核验方法
- `assets/`：队伍状态、AI 使用记录和任务卡模板
- `agents/openai.yaml`：Codex 界面元数据
